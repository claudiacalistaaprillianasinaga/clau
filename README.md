# 🎮 Project Game Claudia 🚀

Koleksi game interaktif web edukatif, simulasi, puzzle kognitif, dan logika yang dibuat oleh **Claudia Calista Aprilliana Sinaga**.

---

## 🌟 Daftar Game & Aplikasi Utama

### 🧠 1. Neuro-Paradox: The Dual-Brain Cognitive Reflex Lab (`NeuroParadox.html`)
Game latihan ketangkapan otak dan refleks kognitif tingkat tinggi:
- **Mode 1: Paradox Blitz** — Memadukan Stroop Effect dengan arahan paradoks spontan (memilih warna yang salah/kebalikan untuk mematikan mode autopilot otak).
- **Mode 2: Dual-Hemisphere Multitasking** — Melatih sinkronisasi otak kiri (menyeimbangkan gyro platform dengan tombol A/D) dan otak kanan (menghitung paritas ganjil-genap cepat dengan tombol 1/2).
- **Mode 3: Quantum Cipher Matrix** — Uji memori kerja spasial dan audio-visual 4x4.
- *Didukung Web Audio API Synthesizer procedural real-time dan Neural Canvas background.*

### 🍳 2. Master Chef Culinary Lab & Math Kitchen (`cooking.html` / `masak.html`)
Game simulasi memasak interaktif dengan elemen matematika kuliner:
- Bebas memilih aneka menu masakan autentik (Nusantara, Asian Ramen, Western Gourmet Steak, Pastry & Dessert).
- Tantangan takaran porsi, rasio bumbu matematika, dan waktu memasak presisi.

### 📐 3. Flowgorithm Studio Deluxe 3-in-1 (`flow.html` / `flowgorithm.html`)
Media pembelajaran logika pemrograman visual:
- **Kuis Diagram Alir (Flowchart)**: Menebak blok flowchart yang hilang dengan efek suara.
- **Hukuman 8-Puzzle**: Hukuman interaktif ketika melakukan 3 kesalahan.
- **Live Simulator & Variable Watch**: Menjalankan flowchart secara real-time.
- File sumber: `TebakAngka.fprg`.

### 🖐️ 4. FingerVision (`FingerVision.html`)
Game interaktif pelacak visual dan gestur tangan menggunakan teknologi Computer Vision berbasis browser.

### 🚆 5. RailNusa & DelMate (`RailNusa.html`, `DelMate.html`)
Aplikasi simulasi reservasi, navigasi stasiun kereta api nusantara, dan platform interaktif edukasi kampus Del.

## 🚀 Cara Menjalankan
1. Clone repositori ini:
   ```bash
   git clone https://github.com/claudiacalistaaprillianasinaga/project-game-claudia.git
   ```
2. Buka file `.html` mana pun langsung di browser modern pilihanmu (Google Chrome, Microsoft Edge, Mozilla Firefox).
3. Tidak memerlukan instalasi server tambahan (100% standalone HTML5, CSS3, & Modern JavaScript).
